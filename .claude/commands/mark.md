# mark

Read the roll, confirm the instructor evidence, then mark present, absent or excused. Missing is unknown. Future marks fail.

```bash
node scripts/swim.mjs mark --student=<code> --session=<lesson> --status=present
```

Read current records. Report facts from the output; ask for missing write values. Read commands accept --json. Ambiguous matches list candidates and exit 1. Nothing sends from this system.
