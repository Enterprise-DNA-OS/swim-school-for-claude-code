# drop

Read the existing placement and confirm the requested change. Ends the placement today and retains earlier rolls. Do not erase history.

```bash
node scripts/swim.mjs drop --student=<code> --class=<code> --note="<reason>"
```

Read current records. Report facts from the output; ask for missing write values. Read commands accept --json. Ambiguous matches list candidates and exit 1. Nothing sends from this system.
